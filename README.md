# Joejosue.com

This repo is the Joejosue.com site.

It is a static HTML site.
There is no `package.json` and no build toolchain.
The live page is `index.html`.
Extra CSS lives in `style.html`.

To run it locally, open `index.html` in a browser.
There is no install step and no build command.

GitHub Pages deploys from the `main` branch root.
The live site is https://joejosue.com/.
The `CNAME` file sets that custom domain.

The Ahensya look comes from https://github.com/joe-josue/ahensya-design-system.
